# Predicting NBA Player Positions Using Machine Learning

This project uses supervised and unsupervised machine learning to predict whether NBA players are guards or non-guards based on player-season statistics.

## Methods Used
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- K-Means Clustering
- Hierarchical Clustering

## Tools
- R
- Tidyverse
- caret
- e1071
- cluster
- factoextra

## Results
The SVM model achieved the best supervised learning performance with about 90% test accuracy. Clustering methods showed weaker natural separation, suggesting that modern NBA positions are increasingly flexible and overlapping.
